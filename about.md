# <c-34E89E>E</c><c-32E49E>d</c><c-30E09F>i</c><c-2EDC9F>t</c><c-2DD89F>o</c><c-2BD4A0>r</c> <c-27CDA0>P</c><c-25C9A0>h</c><c-23C5A1>y</c><c-22C1A1>s</c><c-20BDA1>i</c><c-1EB9A2>c</c><c-1CB5A2>s</c>
Bring real-time <c-34e89e>physics simulation</c> right into the Geometry Dash level editor!

## Usage
1. Select one or multiple objects you want to <c-3b82f6>apply physics</c> to
2. Click the <c-3b82f6>toggle physics button</c> in the top menu or press your <c-3b82f6>customizable keybind</c>
3. The simulation <c-3b82f6>will start</c>! It will <c-3b82f6>stop automatically</c> when objects settle, or you can <c-3b82f6>stop it manually</c> by pressing the button again

## Supported objects
- Solids (Standard blocks)
- Slopes
- Spikes
- Circular objects

## Configuration
- World <c-3b82f6>gravity strength</c> and <c-3b82f6>physics refresh rate</c>
- Dynamic objects' <c-3b82f6>physics parameters</c> (Friction, Bounciness, Damping)
- <c-3b82f6>Random impulse options</c> to apply a physical force to objects on simulation start
- Toggle button position settings
- Customizable keybind for toggling the simulation
