Bring real-time physics simulation right into the Geometry Dash level editor!

## Usage
1. Select one or multiple objects you want to apply physics to
2. Click the toggle physics button in the top menu or press your customizable keybind
3. The simulation will start! It will stop automatically when objects settle, or you can stop it manually by pressing the button again

## Supported objects
- Solids (Standard blocks)
- Slopes
- Spikes
- Circular objects

## Configuration
- World gravity strength and physics refresh rate
- Dynamic objects' physics parameters (Friction, Bounciness, Damping)
- Toggle button visibility and its position settings
- Customizable keybind for toggling the simulation
